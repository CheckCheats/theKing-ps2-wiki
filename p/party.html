左侧组队系统

屏幕左侧中上区域：组队 / 邀请 + 当前任务追踪。这是玩家小队，不是匹配队列小游戏。

规则

  • 队伍人数上限 5（maxPartyMembers / PartyMaxSize = 5）。
  • 未组队时可点 Create Party / 组队 建队。
  • 输入框：（在这里输入玩家名称来邀请他…） → 按名邀请；支持从当前服玩家 / 好友自动补全。
  • 可开关：接收邀请、队内 PVP 等（顶栏相关按钮）。
  • 成员可离开 / 被踢；长按成员可尝试传送到其所在服务器（若未被禁止）。
截图里若出现 1/10，那是 Boss 猎杀「可接任务槽位」计数（见下文），不是队伍 1/10。
右上或侧栏的 人数/人数上限（如 19/100）一般是当前服务器人数，与队伍上限无关。

任务追踪条

组队栏下方显示当前进行中的任务。Boss 猎杀接取后典型长这样：

  • 标题：Eliminate Obari · 进度 0/1
  • 目标：Defeat Obari · 同样 0/1
  • 倒计时：默认任务时限 1800 秒（30 分钟），界面显示剩余如 9:41
  • 奖励预览：精通 / 经验 与 文（星币图标）

奖励怎么算（Boss 猎杀）

  • 基础：按猎杀等级与稀有度系数算出 Exp，再 Wen ≈ Exp × 0.45。
  • 账号已满级：Exp 换成固定精通 FlatMastery ≈ round(Exp ÷ 2)，追踪条就显示「精通 +N」。
  • 队伍人数会影响结算系数（例如仅 1 名合格成员时约 ×0.5；私人服再乘 0.5 等）。
  • 同时进行的 Boss 猎杀任务：每人最多 1 个；接取冷却约 30 秒；不可普通取消（NoCancel）。
  • 击杀贡献可共享（KillCreditShare ≈ 0.1）。

Obari 示例：史诗级猎杀、推荐等级约 200、最低约 125；满级时追踪条常见精通 + 文组合。

Boss 猎杀「排队 / 栏位」（NPC 对话里）

向乌鸦 / 无惨侧接猎杀时，界面会显示类似 已接 / 上限：

  • 每侧最多开放 MaxOpen = 5 个猎杀栏。
  • 人类 / 猎杀队走 Crow 侧；鬼走 Muzan 侧；混血可走两侧 → 合计最多 10。
  • 所以混血看到的 N/10 = 已占用栏位 / 10，不是组队人数。

接取后左侧出现追踪条；完成后栏位释放。详细 Boss 与掉落见 巢穴猎杀 / Boss。

和「匹配队列」的区别

另有小游戏 / 地图传送用的 Queue 设置，与左侧组队栏无关。日常组队只走本页的 Party + 猎杀栏位。
