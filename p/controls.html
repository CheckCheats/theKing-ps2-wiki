游戏怎么操作

PC 默认以键鼠为主。打开菜单 M → 设置 → 控制 可改部分按键与开关。下列说明按默认键位书写。

基础移动

  • WASD：移动（不可改）。
  • 空格：跳跃；解锁技能树「二段跳」后可空中再跳。
  • 左 Shift：跑步 / 冲刺。见下方「切换跑步」开关。
  • 左 Alt：视角换档锁定（Shift Lock）。
  • Q + 方向：闪避冲刺（Dash），耗体力，约 1 秒冷却。Q 为系统保留键，不可改绑。

战斗

  • 鼠标左键：普攻（M1）。可按住连段；跑步中第一下可为跑攻；空中配合跳跃可上挑。
  • F（技能 1）：默认格挡（按住）。多数武器 / 呼吸都会带 Blocking，占技能栏第 1 格。
  • Z / X / C / V / B：技能 2～6，对应呼吸 / 邪恶艺术 / 武器主动技（技能树里标注的默认键）。
  • N / K / L / J：技能 7～10，用于公会技、体术等额外技能槽。
  • 技能消耗体力，有冷却；终极大招通常还要先打过对应 Boss。

物品与菜单

  • 1～5：快捷栏工具 1～5（药水、武器切换等）。
  • M：打开主菜单（库存 / 技能树 / 商店 / 设置…）。
  • E：表情（需 Emotes 相关权限时可用）。
  • T：靠近交互、攀爬等提示操作常用键。

设置 → 控制

路径：M → 设置 → 控制。左侧还有「综合」页；底部可重置回默认。

开关

选项默认说明
切换跑步（Toggle Sprint / Toggle run）关开：点一下切换跑步状态；关：按住 Shift 才跑。截图里若为开，是玩家改过。
严格的换档锁定（Strict Shift Lock）关更严格的锁视角行为；对手柄 / 手机影响更明显。

手柄 / 手机另有方向冲刺、瞄准辅助等选项（综合或平台相关页）。

以下按键被系统保留，一般不能绑到自定义操作：WASD、空格、Q、E、M、Esc、Tab、`、/、T、R 等。

萌新游玩顺序建议

  1. 习惯 Shift 跑、Q 闪、F 格挡、左键普攻。
  2. 打开 技能树 先点角色树的生存属性与二段跳。
  3. 学会呼吸或邪恶艺术后，按 Z→X→C→V 逐步解锁，大招 B 需打导师 / Boss。
  4. 需要改键时只改「控制」页列表项；改完用一场训练场试手感。
